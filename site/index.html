Pourquoi

Ce que les mémoires « cloud » ne font pas

Rien ne sort de la machine

Un fichier SQLite est la source de vérité. Pas de base vectorielle, pas de service tiers, pas de clé obligatoire. Fonctionne hors ligne avec un modèle local, ou avec Claude, OpenAI, Gemini si vous le décidez.

Auditable ligne par ligne

Journal append-only, chaîné SHA-256, horodaté et attribué. Même le logiciel ne peut pas modifier ou supprimer une ligne. Toute altération externe est détectée par verify.

Dit, pas déduit

Un fait n'est retenu que s'il est ancré dans ce que la personne a écrit, vérifié mécaniquement. Une page web ou un document est une donnée : l'instruction qui s'y cache part en quarantaine.

Un validateur hors modèle

Secrets, canaris, valeurs périmées, instructions externes suivies : bloqués avant la réponse, par des règles dures. L'adhésion aux consignes ne dépend jamais du modèle seul.

Fonctionnement

Le modèle propose, la mémoire décide

Trois couches, chacune déduite de la précédente. Le journal est la seule vérité ; l'index et le profil compilé se reconstruisent à l'identique à partir de lui.

01 · JOURNAL

Tout est écrit

Chaque tour, chaque fait, chaque oubli devient un événement daté, attribué et chaîné. Plein texte sur l'ensemble, y compris ce qui est désindexé.

02 · POLITIQUE

Porte d'écriture

Durabilité, conflit (fusion versionnée), saillance, sensibilité. Un fait sensible attend une validation humaine. Quatre niveaux d'autonomie, de « observer » à « routines ».

03 · INDEX

Rappel hybride

Lexical pondéré (racines, synonymes FR/EN, idf) qui décide quand il trouve ; sémantique en recours pour les reformulations. Activation ACT-R : ce qui sert reste, ce qui ne sert plus s'efface de la vue.

04 · SOMMEIL

Consolidation testée

Dédoublonnage, abstraction, élagage, compilation d'un profil. L'état consolidé n'est promu que si les suites de tests passent ; sinon, annulé. Tout est journalisé.

128

tests automatisés, verts sous Linux et Windows, Python 3.10 à 3.13.

0

dépendance obligatoire. Bibliothèque standard uniquement ; le chiffrement des sauvegardes est un extra.

13

RGPD

Les droits de la personne, sans toucher au journal

Un dossier mémoire = une personne. Les droits s'exercent sur le dossier entier, ce qui préserve l'immuabilité du journal.

ART. 15 · 20 — ACCÈS, PORTABILITÉ
python -m memoryaicm export --out export.jsonl

Tout le journal, un événement par ligne, hachages inclus : revérifiable sans l'outil.

SAUVEGARDE CHIFFRÉE
python -m memoryaicm backup --out mem.maicm

Instantané cohérent du journal, AES-256-GCM, clé propre au dossier et jamais copiée dans la sauvegarde.

ART. 17 — EFFACEMENT
python -m memoryaicm erase --yes

La clé est détruite : toutes les sauvegardes chiffrées deviennent illisibles. Chaque fichier est écrasé puis supprimé. Seule reste une pierre tombale datée, sans contenu.

Questions

Ce qu'on nous demande

Où vont mes données ?

Dans un dossier sur votre disque : journal.sqlite (la vérité), index.sqlite (reconstructible), un profil compilé. Aucune requête réseau n'est faite par la mémoire elle-même. Si vous branchez un modèle distant pour l'extraction des faits, c'est ce modèle qui reçoit le texte des tours, pas le journal.

Est-ce comparable à Mem0, Zep ou Letta ?

Ce sont de bons produits, pensés pour le cloud et notés par un juge GPT-4o. memoryaicm est pensé pour tourner en local sans dépendance, avec un journal immuable et un validateur hors modèle. Nous publions notre mesure (récupération pure, sans juge) et ses limites ; nous ne comparons pas des chiffres qui ne mesurent pas la même chose.

Pourquoi l'AGPL ?

Pour que le logiciel reste libre, y compris quand il est offert comme service en ligne : qui l'améliore et l'héberge doit publier ses améliorations. Les entreprises qui ne veulent pas de cette obligation prennent la licence commerciale ; c'est ce qui finance le développement.

Quels modèles ?

N'importe lequel. Avec appel d'outils (Claude, GPT, Gemini, Llama, Qwen, Mistral via Ollama, llama.cpp, LM Studio, vLLM) ou sans : un protocole texte existe pour les modèles qui ne savent pas appeler d'outils. Sans aucun modèle, un extracteur à règles FR/EN fait tourner l'ensemble hors ligne.

Et le droit à l'effacement, avec un journal qu'on ne supprime jamais ?

Un dossier = une personne. L'effacement détruit la clé de chiffrement des sauvegardes, écrase puis supprime chaque fichier du dossier. Le journal n'est pas édité ligne par ligne : il est effacé en entier, ce qui est précisément ce que demande l'article 17.

Windows, Linux, macOS ?

Les trois. Python 3.10 ou plus. Les tests tournent sous Linux et Windows en intégration continue. L'installeur en un clic de l'offre Pro vise Windows ; sur les autres systèmes, une commande suffit.
